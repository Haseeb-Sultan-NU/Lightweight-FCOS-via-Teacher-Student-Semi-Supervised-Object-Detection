## 📌 Project Overview
This repository contains the training pipeline, inference engine, and hardware evaluation scripts for an edge-optimized **Fully Convolutional One-Stage (FCOS+) Object Detector**. 

Built on a lightweight ResNet-50 backbone, this model was trained using a custom **Semi-Supervised Object Detection (SSOD)** distillation architecture. By utilizing a Dual-Stream Dataset Buffer, the Student model successfully absorbs the high-level spatial reasoning of a massive Teacher model's pseudo-labels while remaining mathematically grounded by human-annotated ground truth.

Designed for stability on constrained cloud hardware, the custom training loop features dynamic VRAM management, ensuring uninterrupted training on massive datasets. The resulting model achieves **~49% standard mAP** on the strict COCO 2017 validation set and is capable of real-time inference on edge devices and consumer CPUs.

---

## 🚀 Key Engineering Features

* **Dual-Stream Distillation Engine:** A custom `DataLoader` that simultaneously processes human-verified ground-truth (COCO instances) and synthetic Oracle predictions (pseudo-labels) in the exact same batch to prevent model hallucination.
* **Hardware-Resilient Training Loop:** Engineered to prevent VRAM fragmentation and CUDA Out-Of-Memory crashes on T4 GPUs. Includes:
  * **Active NaN-Blocker:** Detects mathematical explosions (inf/NaN loss spikes) and safely purges the computational graph before it poisons the model weights.
  * **Unified Backward Pass:** Optimizes gradient accumulation and dynamically flushes dead VRAM caches.
* **Universal Hardware Benchmarking:** Built-in asynchronous CUDA timing and CPU performance counters to measure exact Frame-Per-Second (FPS) and millisecond latency across NVIDIA GPUs, Apple Silicon, and standard CPUs.
* **Automated Cloud Recovery:** Epoch and batch-level state saving ensures the training pipeline can resume seamlessly after cloud disconnections.

## 🧠 Data Distribution Scale
This model was trained across a massive data topology utilizing the COCO 2017 dataset to ensure high-level environmental generalization:

* **The Labeled Anchor Stream:** `117,266 images`
  * Human-annotated ground truth used to prevent model hallucination.
* **The Unlabeled Oracle Stream:** `112,987 images`
  * Synthetic pseudo-labels generated by the Teacher model to transfer advanced spatial reasoning.
* **The Blind Validation Set:** `5,000 images`
  * Used exclusively for strict TorchMetrics mAP evaluation. The model never sees these during training.
* **Total Scale:** The pipeline safely orchestrates over **230,000+ training environments** per epoch without hardware failure.
